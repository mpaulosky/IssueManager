# fix(sandcastle): Run the YAML, workflow and shell lints in the sandbox check

- **Release tag:** `v0.0.84`
- **Source PR:** [#329](https://github.com/mpaulosky/IssueManager/pull/329)

## PR description

`.sandcastle/check.sh` is the gate the host runs in the sandbox (`GATE_COMMAND`), but it ran only markdownlint of the gate's lints. The Dockerfile installs yamllint, actionlint, shellcheck and zizmor, and nothing used them, so a branch that broke a workflow, YAML file or shell script passed both checkpoints and failed CI's lint workflows afterwards.

- `check.sh` now runs the same lints as `scripts/gate.sh`: yamllint on the changed YAML, actionlint and `zizmor --offline --min-severity medium .` when a workflow changed, and shellcheck on the changed shell scripts. A tool that isn't installed (a run outside the image) is skipped with a warning, as the gate does.
- Its header comment now says which tools the image provides, instead of that it lacks them.
