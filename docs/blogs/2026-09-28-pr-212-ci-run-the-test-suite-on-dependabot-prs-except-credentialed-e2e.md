## ci: Run the test suite on Dependabot PRs, except credentialed E2E

- **Release tag:** `v0.0.35`
- **Source PR:** [#212](https://github.com/mpaulosky/IssueManager/pull/212)

### PR description

The CI workflow skipped test discovery, every test job, coverage and the report job whenever Dependabot opened the PR. GitHub counts a skipped check as passing, so the required test check went green on Dependabot bumps without a single test run. Dependabot PRs now run the test suite too.

**Except credentialed E2E.** The Playwright (E2E) projects log in to Auth0 with real credentials, and an unreviewed dependency bump must not run with those. Test discovery therefore leaves them out on Dependabot PRs, and they run on `main` once the bump merges. No other test project reads a secret, so no Dependabot secrets are needed.

Dependabot runs always get a read-only `GITHUB_TOKEN`, so the step that publishes the "Test Results Summary" check run and PR comment still skips there. The required test check still fails when any test did.

Validation: no new `actionlint` or `yamllint` findings in the changed file; I simulated discovery with and without Dependabot, and the pre-push hook passed.
