# build(deps): Update NuGet packages

- **Release tag:** `v0.0.76`
- **Source PR:** [#307](https://github.com/mpaulosky/IssueManager/pull/307)

## PR description

_Requested by **Matthew** · [project thread](https://claude.ai/code/project/chan_01M4TRjuaTvMLM1jqeNd9KNs?thread=cmsg_01M4TRjuaTvMLM1jqeNd9KNs3RNc9yDo6fauxomeH8GaE4)_

### Why

The NuGet packages had fallen behind their latest stable releases, and the Aspire packages had drifted apart: the
AppHost project used `Aspire.AppHost.Sdk` 13.5.3, `Directory.Packages.props` listed the SDK at 13.4.6, and the Aspire
packages were on 13.4.6 and 13.6.0 side by side. This brings every package to its latest stable release and aligns all
of Aspire on 13.6.1.

### What changed

Aspire, all on 13.6.1:

- `Aspire.AppHost.Sdk` (AppHost project SDK) 13.5.3 → 13.6.1, and its `Directory.Packages.props` entry 13.4.6 → 13.6.1
- `Aspire.Hosting`, `Aspire.Hosting.MongoDB`, `Aspire.Hosting.Redis`, `Aspire.Hosting.Testing` 13.6.0 → 13.6.1
- `Aspire.StackExchange.Redis.OutputCaching` 13.4.6 → 13.6.1

Major update:

- `MongoDB.Entities` 25.1.0 → 26.0.0 (builds and passes every test with no code change)

Minor and patch updates:

- `AngleSharp` 1.8.3 → 1.8.5
- `FluentValidation` 12.1.1 → 12.2.0
- `MessagePack` 3.1.11 → 3.1.12
- `Microsoft.AspNetCore.Authentication.JwtBearer`, `Microsoft.AspNetCore.Components.Web`,
  `Microsoft.AspNetCore.Mvc.Testing`, `Microsoft.AspNetCore.OpenApi` 10.0.12 → 10.0.13
- `Microsoft.Extensions.ServiceDiscovery` 10.10.0 → 10.11.0
- `Microsoft.NET.Test.Sdk` 18.10.1 → 18.11.0
- `Microsoft.Testing.Extensions.CodeCoverage` 18.11.2 → 18.12.0
- `Microsoft.Testing.Extensions.Telemetry`, `Microsoft.Testing.Extensions.TrxReport.Abstractions`,
  `Microsoft.Testing.Platform.MSBuild` 2.4.0 → 2.5.1
- `OpenTelemetry`, `OpenTelemetry.Api`, `OpenTelemetry.Exporter.OpenTelemetryProtocol`,
  `OpenTelemetry.Extensions.Hosting` 1.19.1 → 1.20.0
- `OpenTelemetry.Instrumentation.AspNetCore`, `OpenTelemetry.Instrumentation.Http`,
  `OpenTelemetry.Instrumentation.Runtime` 1.19.0 → 1.20.0
- `Radzen.Blazor` 12.0.5 → 12.1.4
