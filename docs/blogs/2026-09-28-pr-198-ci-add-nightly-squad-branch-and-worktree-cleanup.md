## Summary

Ports the nightly squad branch/worktree cleanup from `mpaulosky/Articles`:

- `.github/workflows/squad-branch-worktree-cleanup.yml`
- `scripts/squad/cleanup-squad-branches.sh`

## Behaviour

- **Scheduled (03:35 UTC):** applies cleanup. Deletes branches matching `squad/{n}-…`, `sprint/{n}-…`, `hotfix/…`, `chore/…` whose PR merged (including squash merges), and orphans that are unmerged, have no open PR and are older than 14 days. A closed-but-unmerged PR counts as abandoned.
- **Manual dispatch:** dry run by default. Applying needs `apply=true` **and** `apply_signal=APPLY_CLEANUP`.

## First-run impact

A dry run before opening this PR found **no remote branches** matching the cleanup pattern, because head branches are already auto-deleted on merge. The first scheduled run has nothing to delete; the job only affects branches created from now on.
