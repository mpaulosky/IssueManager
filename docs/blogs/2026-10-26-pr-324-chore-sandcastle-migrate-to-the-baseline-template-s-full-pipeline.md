# chore(sandcastle): Migrate to the Baseline Template's full pipeline

- **Release tag:** `v0.0.81`
- **Source PR:** [#324](https://github.com/mpaulosky/IssueManager/pull/324)

## PR description

Closes #323.

Moves this repo's `.sandcastle/` from the older single-implementer pipeline onto the full one the repo-ci-baseline Template now owns (mpaulosky/dotfiles#280, mpaulosky/dotfiles#282).

- `apply.sh`: the Template's Owned files (the whole `.sandcastle/` pipeline and the other Owned drift: four workflows, `docs/PROCESS.md`) and the Seed role files.
- Taken from the Template by hand: `Dockerfile`, `plan-prompt.md`, `review-prompt.md`. Removed the old `implement-prompt.md` and the old pipeline's `check`, `git`, `publish` and `verdict` modules.
- `node` is now `tsx`, with `tsx` added, and `test:sandcastle` is now `check:sandcastle` everywhere it is called.
- `pnpm-workspace.yaml` gains `allowBuilds: esbuild: false`, as the Template's does.
- Fixes the local run, which failed with `Cannot mount file to '.git/config'`.

`pnpm run check:sandcastle` passes and the pre-push gate passed.

Not done: this repo's own `CODING_STANDARDS.md` and `check.sh` are kept as they were.
