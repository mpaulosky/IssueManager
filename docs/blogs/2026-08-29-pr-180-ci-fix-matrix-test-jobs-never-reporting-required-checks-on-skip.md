# ci: fix matrix test jobs never reporting required checks on skip

- **Release tag:** `v0.0.20`
- **Source PR:** [#180](https://github.com/mpaulosky/IssueManager/pull/180)

## PR description

### Summary

- Fixes a bug found while merging #179: docs/config-only PRs never actually satisfy the branch ruleset's per-project `Tests: *` required status checks, leaving them permanently missing (not skipped) and blocking merge.
- Root cause: a job's `if:` is implicitly ANDed with `success()` unless it uses `always()`. `discover-tests` and `test` both depend on `build`, which is intentionally skipped on docs-only PRs — so both were silently skipped too, and a skipped matrix job never creates the individually-named check runs the ruleset requires.
- Adds `always()` to `discover-tests` and `test` (matching the existing pattern already used by `coverage` and `report`), plus an explicit `needs.changes.outputs.code == 'true'` gate on `test`, so each matrix entry now reports `SKIPPED` by name instead of never reporting at all.
