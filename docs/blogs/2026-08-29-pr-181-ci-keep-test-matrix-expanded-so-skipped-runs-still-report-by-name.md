# ci: keep test matrix expanded so skipped runs still report by name

- **Release tag:** `v0.0.21`
- **Source PR:** [#181](https://github.com/mpaulosky/IssueManager/pull/181)

## PR description

### Summary

Follow-up to #180, which fixed the wrong half of this problem. #180 added `always()` so the `test` job stays scheduled when `build` skips, but the job-level `if:` still gated on `needs.changes.outputs.code` — and a matrix job skipped at the job level collapses into a single unexpanded `Tests: ${{ matrix.test_name }}` check instead of one per project. The ruleset's per-project required checks (`Tests: Api.Tests.Unit`, etc.) still never got created, and #179 stayed blocked (confirmed after merging #180 and rebasing #179 onto it).

Fix: move the `needs.changes.outputs.code == 'true'` gate from the job level down to each functional step (Restore, Build test project, Install Playwright, Run tests, Upload artifacts). The job's own `if:` is now just `always() && actor != dependabot`, so the matrix always expands into its real per-project check names — each entry just no-ops to a quick success when nothing needs testing, instead of collapsing away.
