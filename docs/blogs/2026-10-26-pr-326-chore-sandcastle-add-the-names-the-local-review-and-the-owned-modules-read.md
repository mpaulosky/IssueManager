# chore(sandcastle): Add the names the local review and the Owned modules read

- **Release tag:** `v0.0.82`
- **Source PR:** [#326](https://github.com/mpaulosky/IssueManager/pull/326)

## PR description

Prepares IssueManager for the re-Apply that brings the Baseline's local review (mpaulosky/dotfiles#289, #290, #292, #294).

- `.sandcastle/lib/repo-config.mts`, which Apply never rewrites, gains four names the Owned modules import:
  - `REPO_SLUG` and `NOT_OWNED_BASELINE_PATHS`, the latter listing the four files here under an Owned pattern that the Template lacks (the four `.github/instructions` files).
  - `GATE_SCRIPT` (`.sandcastle/check.sh`, the file `GATE_COMMAND` runs) and `CHECK_PATHS` (the Seed's default list). Without them the re-Apply fails its Sandcastle type check.
- `.claude/settings.json`: denies Claude Code reading the local review's ledgers (`.git/review`) and the usual credential files.

Nothing reads the new names until the re-Apply.
