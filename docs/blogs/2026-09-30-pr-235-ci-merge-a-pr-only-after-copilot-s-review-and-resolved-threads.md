## ci: Merge a PR only after Copilot's review and resolved threads

- **Release tag:** `v0.0.45`
- **Source PR:** [#235](https://github.com/mpaulosky/IssueManager/pull/235)

### PR description

Part 3 of #227.

## Why

`pr-automerge.yml` armed GitHub's native auto-merge, or merged directly on `CLEAN`/`UNSTABLE`, as soon as the required checks passed. Copilot's review is requested on every push but isn't a required check, so PRs routinely merged before the review arrived. #231 merged with an unresolved Copilot thread this way.

## What changes

- **`.github/scripts/automerge-decision.mjs`**: the decision now takes `copilotReviewedHead`, `unresolvedThreads` and `threadsTruncated`, and returns `skip`, `wait` or `merge`. It never arms native auto-merge, which merges the moment checks pass. A PR merges only when Copilot has reviewed its exact head commit, every review thread is resolved, and the merge state is `CLEAN` or `UNSTABLE` (kept from #205). Drafts, forks, conflicts and PRs with auto-merge already armed are skipped. Those last are release blog PRs and Dependabot's PRs, which `dependabot-auto-merge.yml` still merges on green required checks, as IssueTracker's does. More than 100 threads is left to a person.
- **`.github/scripts/tests/automerge-decision.test.mjs`**: rewritten, 16 tests. 8 fail against the old module; all pass now.
- **`.github/workflows/pr-automerge.yml`**: rewritten after IssueTracker's. It runs on `pull_request_target`, on `workflow_run` completion of every workflow that owns a required check, on a 15-minute schedule (resolving a thread has no trigger), and by hand. It checks out only main's `.github/scripts`, reads readiness in one GraphQL query, and squash-merges with `sha` pinned to the checked head, so a push landing in between fails the merge instead of merging unreviewed code. The PAT keeps the merge attributed to a user, so the release workflow still runs.

## Landing this PR

The old workflow on `main` would arm auto-merge on this PR the moment its checks pass. It's a draft so that logic skips it; Copilot's review is requested by hand, every thread gets resolved, and then it's marked ready and merged manually while `CLEAN`.
